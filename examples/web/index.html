LuciaJS features

Each section shows one feature with a live demo and the source behind it.

Text bindings

Put {expr} in text. The text updates when a signal the expression reads changes.

Values are inserted as text, so HTML inside a value is shown as is.

Attributes

A whole attribute, disabled={expr}, follows its value. A partial attribute mixes text and values.

null, undefined and false remove a whole attribute. true sets it empty.

Signals and computed

signal(value) holds state. Read and write it with .value.

computed(fn) derives a value. It updates when the signals it reads change.

batch and untrack

batch(fn) groups writes, so watchers run once at the end.

untrack(fn) and .peek() read a signal without depending on it.

Tree vs scoped styles

Tree styles, the default, reach child components. Scoped styles, from <style scoped> or @scoped { }, stop at them.

The red paragraphs reach the child. The underline does not.

Global styles

Global rules are not scoped. Use <style global>, an @global { } block, or :global() inside a selector.

:global() leaves only the part inside it global. The rest of the selector stays scoped.

SCSS

<style> is SCSS. Use @use to share variables and mixins between files.

Use lang="css" for plain CSS. Each block is still scoped.
